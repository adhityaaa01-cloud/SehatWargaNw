# Illustration generation prompts

Generated with the built-in `image_gen` tool, one call per asset, `transparent_background: true`. Each prompt consisted of the common text below followed by its subject text. The generated PNGs were copied unchanged into `frontend/static/images/services-3d/`.

## Common prompt

Use case: stylized-concept. Asset type: transparent PNG illustration for the right side of a premium Indonesian healthcare web banner. Create a highly detailed premium 3D / isometric studio render, with tangible depth, thick beveled edges, matte white ceramic, satin teal and cyan surfaces, deep blue accents, restrained green approval details, soft natural contact shadows, and realistic ambient occlusion. Consistent orthographic three-quarter camera from slightly above; soft upper-left studio lighting. Rich polished product illustration, NOT flat vector art, NOT simple pictograms, NOT a UI screenshot. Landscape 3:2 composition with the complete compact object cluster centered, 10% transparent safe margin on ALL four sides; no cropped objects. Genuine transparent background with subtle natural shadow only. No colored backdrop, no banner, no UI controls. Absolutely NO text, letters, numbers, words, logos, or watermarks anywhere; document details must use abstract embossed lines and small shapes only.
